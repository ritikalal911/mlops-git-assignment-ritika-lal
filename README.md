
# MLOps Git Assignment 

## Project Description

This repository demonstrates Git branching and collaboration workflows
as part of the MAI201 MLOps course at Seneca College.

## Prerequisites

- Python 3.8+
- Git installed on your machine
- GitHub account

## Setup Instructions

1. Clone the repository
   git clone https://github.com/ritikalal911/mlops-git-assignment-ritika-lal.git
2. Navigate into the folder
   cd mlops-git-assignment-ritika-lal
3. Install dependencies
   pip install -r requirements.txt

## Usage

This project follows a Git branching strategy with main and develop branches.
Feature branches are created from develop and merged back via pull requests.
